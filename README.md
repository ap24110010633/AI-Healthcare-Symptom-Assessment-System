# 🏥 AI Healthcare Symptom Assessment System

## Machine Learning Based Symptom Assessment

## 📌 Project Overview

The **AI Healthcare Symptom Assessment System** is a machine-learning-based educational application that analyzes user-reported symptoms and provides a possible health condition based on patterns learned from a symptom-disease dataset.

The system uses data preprocessing, symptom extraction, multi-hot encoding, machine learning classification, and a Streamlit web application to provide an interactive symptom assessment experience.

> **Important Disclaimer:** This project is developed for educational and academic purposes only. It is not a medical diagnosis or treatment system. The predictions generated by the model may be incorrect and should not replace professional medical advice.

---

## 🎯 Objectives

The main objectives of this project are:

- To develop a machine-learning-based symptom assessment system.
- To preprocess and transform symptom-disease data into machine-readable features.
- To compare multiple machine learning classification algorithms.
- To select a suitable model for symptom-based prediction.
- To develop an interactive web application using Streamlit.
- To provide general educational information about the predicted condition.

## 📊 Dataset

The project uses a structured symptom-disease dataset containing:

- **4,920 original records**
- **18 columns**
- **1 disease column**
- **17 symptom columns**
- **41 disease classes**
- **131 unique symptoms**

The target variable is:

```text
Disease
```

The symptom attributes are:

```text
Symptom_1
Symptom_2
...
Symptom_17
```

### Data Preprocessing

The following preprocessing operations are performed:

1. Disease names are cleaned.
2. Symptom values are converted to a consistent format.
3. Missing symptom values are handled.
4. Rows without symptoms are removed.
5. Duplicate records are removed.
6. Unique symptoms are extracted.
7. Symptoms are converted into binary features using multi-hot encoding.
8. Disease labels are encoded using LabelEncoder.

---

## 🤖 Machine Learning Models

The following classification algorithms were evaluated:

### 1. Decision Tree

A tree-based classification algorithm that makes predictions using a sequence of decision rules.

### 2. Random Forest

An ensemble learning algorithm that combines multiple decision trees to improve prediction performance and robustness.

### 3. Extra Trees

An ensemble tree-based algorithm that introduces additional randomization while constructing decision trees.

### 4. K-Nearest Neighbors

A classification algorithm that predicts the class of a sample based on the classes of nearby training samples.

---

## 🏆 Final Model

The **Random Forest classifier** was selected as the final model for the application.

Configuration:

```text
Algorithm: Random Forest
Number of Trees: 300
Random State: 42
```

The final model is trained using the processed symptom features and disease labels.

---

## 🔢 Feature Representation

Symptoms are represented using **multi-hot encoding**.

For example:

```text
itching     → 1
skin_rash   → 1
headache    → 0
fever       → 0
```

A value of `1` indicates that the symptom is present, while `0` indicates that it is absent.

This representation allows machine learning algorithms to process multiple symptoms as numerical features.

## 📌 Limitations

The system has several limitations:

1. It depends on the quality and structure of the dataset.
2. The dataset contains repeated and structured symptom-disease patterns.
3. Real-world medical conditions may involve symptoms that are not represented in the dataset.
4. The system does not consider complete patient history.
5. It does not use laboratory tests or physical examination results.
6. Model prediction scores should not be interpreted as medical probabilities.
7. The model has not been clinically validated.
8. The application cannot replace a qualified healthcare professional.
